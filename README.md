The orov-out project houses the files related to the analysis of a Oropouche virus case series. It contains:
1) Data: site source data (.xlsx), data dictionaries (.rds/.csv), pediatric lab references.pdf, .geojson administrative border files, .csv files with 2024-2025 reported arboviruses from PAHO and the extracted data (.rds). Clean data after descriptive analysis .RData 
2) Scripts: .R or .qmd rendered in HTML
3) intermediate files: .csv & 
4) outputs: figures for manuscript
5) manuscript: Tables and figures for manuscript

This project is under construction
