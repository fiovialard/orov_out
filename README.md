The orov-out project houses the files related to the publication: "Oropouche virus disease across Latin America during the 2023-2025 epidemic: a multi-country case series". 

It contains:
1) Data: site source data (.xlsx), data dictionaries (.rds/.csv), pediatric lab references.pdf, .geojson administrative border files, .csv files with 2024-2025 reported arboviruses from PAHO and the extracted data (.rds). Clean data after descriptive analysis .RData, codebook 
2) Scripts: .R or .qmd rendered in HTML
3) Intermediate files: .csv & .RData files, outputs for presentations
4) Outputs: figures for manuscript
5) Manuscript: Tables and figures for manuscript and associated files for formatting

This project is under construction
